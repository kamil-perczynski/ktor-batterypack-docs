# Request Binding

The Core module provides `JsonBinder` and `QsBinder` for converting and validating incoming request data. Both are built on the shared Jackson mapper.

## `JsonBinder`

`JsonBinder` receives a request body or query parameters, validates the intermediate Jackson node, and converts it to a typed object.

### Binding the request body

```kotlin
import io.github.ktor_batterypack.core.ktor.JsonBinder
import io.ktor.server.application.call
import io.ktor.server.response.respond
import io.ktor.server.routing.Routing
import io.ktor.server.routing.post
import org.koin.core.annotation.Singleton

@Singleton
class UserController(
    private val jsonBinder: JsonBinder,
    private val userApiValidator: UserApiValidator
) : KtorController {

    override fun register(routing: Routing) {
        routing.post("/users") {
            val createUser = jsonBinder.bindBody<UserCreateDto>(
                call,
                userApiValidator::checkUserCreateDto
            )
            call.respond(userService.create(createUser))
        }
    }
}
```

The flow is:

1. Read the body as a Jackson `JsonNode`.
2. Run the validator function, which returns a `ValidationResult<JsonNode>`.
3. If validation fails, throw `ValidationException` mapped to a 400 `ProblemDetail`.
4. Convert the validated node to the target type with Jackson.

### Binding query parameters

```kotlin
routing.get("/users") {
    val query = jsonBinder.bindQueryParams<ListUsersParamsDto>(
        call,
        userApiValidator::checkListUsersParamsDto
    )
    call.respond(userService.findAll(query))
}
```

Query parameters are first converted to a nested `JsonNode` by `QsBinder`, then validated and mapped.

## `QsBinder`

`QsBinder` turns flat Ktor query parameters into a nested Jackson tree. Dot-separated keys are interpreted as object paths, and numeric segments are interpreted as array indices.

| Query string | Resulting JSON |
|--------------|----------------|
| `name=John` | `{"name":"John"}` |
| `address.city=Warsaw` | `{"address":{"city":"Warsaw"}}` |
| `items.0.name=apple` | `{"items":[{"name":"apple"}]}` |
| `tag=a&tag=b` | `{"tag":["a","b"]}` |

Sparse array indices are padded with `null` nodes. Root-level numeric keys are rejected.

## Validators

Validator functions are provided by the [Validation](/validation/validation) module or generated by the [Validation Codegen](/validation/validation-codegen) KSP processor. They take a `JsonNode` and return a `ValidationResult<JsonNode>`:

```kotlin
fun checkUserCreateDto(node: JsonNode): ValidationResult<JsonNode> {
    // validate and return the (possibly transformed) node
}
```

`jsonBinder` calls `.check("Invalid request body")` on the result so validation failures produce a consistent error response.
